# **App Name**: PreplexityChat

## Core Features:

- Chat Interface: A user interface for sending and receiving messages. This component allows users to type questions, view responses, and maintain a conversation history.
- Preplexity API Integration: Integrate with the Preplexity AI API to send user queries and receive AI-generated responses, providing intelligent answers and contextually relevant information.
- Settings Storage: A feature to save and utilize the Preplexity API key and search domain filters. This allows users to personalize and manage their interaction with the AI.
- API Key Input: Securely store the user-provided Preplexity API key to authorize requests to the Preplexity AI service.
- Domain Selection: A dropdown list of domains available from Preplexity that can be chosen and used to filter searches.
- AI Response Parsing: Parse the JSON response from the Preplexity API to extract the AI-generated content for display.
- Context-Aware Question Suggestion: The app suggests pertinent domains for your search term, employing an AI tool that intelligently parses search terms and context to refine its domain selection for enhanced results.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) to evoke intelligence and sophistication.
- Background color: Light lavender (#E6E6FA) to complement the indigo.
- Accent color: Vivid purple (#9400D3) to draw attention to key interactive elements.
- Body font: 'PT Sans' a sans-serif font offering a clean, readable appearance, used for the main content and conversation text.
- Headline font: 'Playfair' used to provide an elegant title to each turn in the conversation. Requires that the Body font should be PT Sans, according to Playfair's usage guidelines.
- Use simple, modern icons for actions like send, settings, and clear chat.
- Subtle animations on message arrival and during AI response generation.
